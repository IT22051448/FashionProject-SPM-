🌟 Streamlined E-Commerce Solution for Fashion Retail 🛍️

Welcome to the Streamlined E-Commerce Solution for Fashion Retail! Developed as part of the Year 3, Semester 1 (Y3S1) SPM Project at SLIIT, our platform aims to enhance the user shopping experience with advanced features like Referral Program, Loyalty Program, Automated Order Management, Product and Inventory Management Systems. With a focus on customer satisfaction and retention, we provide a seamless, enjoyable online shopping experience for fashion enthusiasts. 👗👚

I was responsible for creating the Referral and Loyalty programs within the application. Here’s what I worked on:

🛠️ Key Features:
Referral Program 🤝: Users can refer friends and family to join the platform, earning loyalty points for each successful referral.

Loyalty Program 💎: A tiered loyalty system where each tier offers better discounts and rewards. Earn 1/10th of your purchase value as loyalty points.

Tiering System: Admins can assign higher tiers to users with the most loyalty points, granting them exclusive perks and discounts.

CRUD Operations 📝: Developed the ability to Create, Read, Update, and Delete loyalty and referral data.

Mail Notifications 📧: When a Loyalty Member refers a friend or family member, they receive a mail notification with sign up details to the Fashion Retail Application.

Report Generation 📊: Admins can generate reports on user loyalty activity, referral performance, and tier rankings.

Automatic Loyalty and Tier Calculations ⚙️: Loyalty points are automatically calculated based on user purchases, and Tiers are updated parallely when the user is eligible, ensuring a smooth and error-free experience.
